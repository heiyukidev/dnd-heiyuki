# SRD equipment data (bundled)

**Why this folder exists:** the product **intentionally avoids** shipping **copyrighted** Wizards of the Coast book material (for example the full PHB/DMG equipment or magic-item catalogs). Bundled item data is therefore limited to the **open** **SRD / OGL** subset, copied from a community dataset with compatible licensing—**not** “everything in the books.”

JSON files here are copied from the [5e-bits/5e-database](https://github.com/5e-bits/5e-database) project (MIT license). Game text in those files comes from the **D&D 5e SRD** under the **Open Game License (OGL)**; see that repository for license details.

This app does **not** include non-SRD proprietary sources. Tables that need book-only items should enter them manually on the sheet (custom rows) or rely on future features that stay within the same guardrails.
