# Match Draft before the live fight

**Match start** no longer assigns random **Loadout**s and begins the live sim immediately. It opens a **Draft** phase: each seat takes five **Boon offer**s (three **Boons** from one **God**, pick one), builds a unique-key **Loadout** under a max-3 **God pool**, and the event-driven fight starts only when both seats finish. Random five-pick-with-replacement at start is rejected — player choice and god commitment are the point of the Greek-god pivot; ADR 0001’s live sim still applies once **Draft** completes.

## Considered Options

- **Keep random Loadout at Match start** — Rejected: no room for **God** fantasy or Hades-style picks.
- **Draft in Lobby before Match start** — Rejected: awkward with Host start timing and “who’s ready.”
- **Match start → Draft → live fight (simultaneous, hidden)** — Accepted.
