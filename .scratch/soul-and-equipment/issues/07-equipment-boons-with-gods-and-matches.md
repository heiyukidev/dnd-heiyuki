# Equipment Boons with Gods and Matches

## Question

How do **Gods** / **Boons** interact with **Equipment** inside a **Match** once both exist?

Decide: **Boons** that buff weapon types, **Boons** that rewrite **Soul stats**, Draft offers that care about equipped types, and anything else needed so “Equipment Boons that interact with gods and matches” is a sharp next build — without pulling gold/nectar into scope.

## Answer

- **A — Buff weapon types:** Yes. Author catalog **Passive**s (or hybrids) that use the existing carrier-seat **Weapon type** gate. Aim for at least one gated **Passive** per type (Sword / Axe / Wand / Bow) in the next build; exact keys/balance in that build.
- **B — Rewrite Soul stats:** No. **Boons** / **Passive**s do not change Strength / Speed / Vitality on the Soul panel or invent a Soul-stat rewrite layer. Combat stays Passive → Soul → Weapon.
- **C — Draft + Weapon:** Soft cue only. Own **Weapon** already visible; add at most one short favor line from **Weapon type** (Sword → damage kits; Axe → high-damage kits; Wand → sustain / hybrid; Bow → Hermes tempo). No offer reweighting, bans, or offer-card highlights (same discipline as Soul soft guidance).
