# Soul spend step UX

## Question

How does a seat spend after its five **Draft** picks?

Decide: realloc freely among Strength / Speed / Vitality before confirm; what “confirm” looks like; how the own-seat **Soul** panel updates during spending; empty/zero-spend path (confirm with no buys). Opponent fog and leftover-lost-on-confirm are already locked.

## Answer

- **Realloc:** Free +/- on Strength / Speed / Vitality until confirm. Minus refunds **Gold**; cannot go below the rolled base for that stat.
- **Confirm:** Explicit **Confirm** control always available (including 0 spent / full **Gold** remaining). No auto-confirm when **Gold** hits 0 — player may still realloc. Leftover **Gold** lost on confirm (prior lock).
- **Zero-spend path:** Confirm with no bumps is legal; seat is ready for fight with rolled **Soul** only.
- **Panel:** Reuse the own-seat **Soul** panel — live numbers = roll + pending bumps; show remaining **Gold**. Favor line stays frozen to the **rolled** **Soul** (Draft already finished). Exact layout/copy beyond this stays in map fog.
- **Fog:** Opponent final **Soul** (roll + bumps) hidden until fight (prior lock).
