# Domain name for Match currency

## Question

What is the domain name for this **Match**-scoped spendable currency?

Decide: glossary term (e.g. **Gold** vs a thematic name), avoid-list synonyms, and whether UI may say something casual while domain docs stay strict. Does not decide grant size or costs.

## Answer

- **Term:** **Gold** — Match-scoped spendable currency; same word in domain docs and UI.
- **Avoid (domain synonyms):** Nectar, money, cash, points, coin/tribute/drachma as glossary names. **Nectar** stays reserved for a possible later God-bribe concept (see Soul and Equipment out-of-scope), not this purse.
- **UI:** No casual alternate — say **Gold**.
